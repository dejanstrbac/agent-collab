This document describes how tests and processes find shared resources in this repository, and how `agent-collab` isolates each role's environment.

## Resources Used by Tests

- **Database**: e.g., PostgreSQL / Redis / SQLite.
  - Port or socket: `5432` / `$PGPORT`
  - Credentials / Database name: `test_db_$ROLE` or container per role.
- **HTTP / Dev Server**:
  - Dev server port: e.g. `3000` / `$PORT`
- **Temporary Files**:
  - Storage path: `/tmp/$ROLE/...` or `t.TempDir()`

## Per-Worktree Configuration (`.collab.env`)

Each role's worktree contains a `.collab.env` file generated by `isolate.sh` (or `collab-init.sh`). Before running tests or servers in a role worktree, source this file:

```bash
source .collab.env
```

If your project requires dedicated containers or ports per role, implement them in `isolate.sh`.
